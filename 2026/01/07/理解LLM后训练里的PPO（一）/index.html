发表于 2026-01-07

理解LLM后训练里的PPO（一）

在大模型（LLM）后训练（post-training）的语境下，PPO（Proximal Policy Optimization）几乎已经成为事实标准：无论是 RLHF、RLAIF，还是近两年出现的 Agentic RL（如 Search-R1、GRPO），我们都会看到 PPO 或其变体的身影。

然而，一个经常被忽略的问题是：**PPO 在 LLM 后训练中究竟“解决的是什么问题”？**它真的在“教模型变得更聪明”吗？还是在更底层的层面上，承担着一种“分布控制机制”的角色？

本文尝试从 优化视角 + 概率分布视角 出发，重新理解 PPO 在 LLM 后训练中的真正作用。

一、从 TRPO 到 PPO：约束是如何被“代理”的

从算法史来看，PPO 并不是凭空出现的，它直接继承自 TRPO（Trust Region Policy Optimization）。TRPO 的核心思想非常清晰：**每一步策略更新，都必须限制在一个“可信任区域”之内。**数学上，这个“可信任区域”通常通过 KL divergence 约束 来表达。但问题在于：

  • 这是一个 带约束的优化问题
  • 在 高维神经网络参数空间 中，直接求解代价极高
  • 实现复杂、数值稳定性差

PPO 做了一件非常“工程化”、但极其重要的事情：把一个难以直接求解的约束优化问题，转换为一个一阶可优化的无约束目标函数。

这类操作在运筹优化与理论计算机科学中非常常见：将不可微 / 离散 / 非凸的结构，转换为连续、可微、可控的形式，从而“让梯度能够工作”。PPO 的 clip 机制，正是这一思想的体现。

二、LLM 里的“策略”，已经不是单 timestep 的动作

在经典强化学习中，策略 $\pi(a_t \mid s_t)$ 描述的是：在状态 $s_t$ 下，选择一个动作 $a_t$ 的概率。但在 LLM 后训练中，这个定义发生了本质变化。

  • action 不再是一个离散动作，而是 一个 token 接一个 token 的生成过程
  • 策略 $\pi_\theta$ 实际上定义在 token-sequence 空间上的概率分布

换句话说：一次“策略更新”，不再是微调某个动作偏好，而是在整体上调整“生成分布的形状”。

这正是为什么 LLM 的 RL 训练会极其不稳定：训练过程中改变的不是一个动作，而是一整个分布。

三、Ratio：一次 change of measure

PPO 中最核心的量之一是：
$$
r_t = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\text{old}}}(a_t \mid s_t)}
$$
在 LLM 语境下，它可以被理解为：新模型对这段 token-sequence 的概率，与旧模型对同一 sequence 的概率之比。

这个 ratio 有几个非常关键的性质：

  1. 它是无量纲的标量（scalar）
  2. 它不关心 reward 的绝对值，只关心“变化幅度”
  3. 从概率论角度看，它本质上是一种change of measure（测度变换）

换句话说，ratio 刻画的是：策略分布从 $\pi_{\theta_{\text{old}}}$ 到 $\pi_\theta$ 的局部变化程度。

这也解释了一个经常被误解的问题：PPO 并不是在“最大化 reward 本身”，而是在 控制分布更新的尺度。

四、Clip：一个对策略改进的保守下界

真正让 PPO 成为工业标准的，不是 ratio，而是 clip。clip 的形式通常是：
$$
\min \left(
r_t A_t,;
\text{clip}(r_t, 1-\epsilon, 1+\epsilon) A_t
\right)
$$
这一步有几个非常重要的含义：

  • 它在目标函数层面 隐式地实现了 TRPO 的“更新幅度约束”
  • 它是可微的，因此可以直接用一阶优化
  • 它通过 min() 构造了一个对真实策略改进的保守下界（pessimistic lower bound）

从直觉上讲：如果某次更新“太激进”，PPO 会选择“假装你没有获得那么多好处”。这也是为什么 PPO 宁愿慢一点，也不允许策略分布发生剧烈跳变。

值得注意的是，这种“控制框架”已经成为 LLM RL 的事实范式，无论是PPO，GRPO，亦或是各种 clipped surrogate objectives，它们的核心精神是一致的。

五、Reward 并不是主角

在很多初学者的理解中，RLHF ≈ 奖励建模 + PPO。但从 PPO 的数学结构来看，reward 并不是最核心的部分：

  • reward 只是被 attach 到 trajectory 上的一个信号
  • 它通常集中在 sequence 的最后一个 token
  • 真正决定更新形态的，是ratio × advantage × clip

因此可以说：PPO 在 LLM 后训练中的主要作用，不是提升生成能力本身，
而是提供一个“可控、可优化的分布更新机制”。

六、小结：PPO 在 LLM 后训练中到底做了什么？

如果用一句话总结：PPO 并不负责“教模型学什么”，它负责“限制模型学得有多猛”。它通过 surrogate objective 与 clip 机制，将不可控的策略分布更新转换为一个稳定、连续、可优化的过程，使模型能够在遵循人类偏好或任务奖励的同时避免分布塌缩与训练崩溃。在LLM时代，PPO 也许不是最“优雅”的算法，却是最可靠的算法。
